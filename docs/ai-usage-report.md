## Benefits and Challenges
Using AI helped me speed up the development process by providing initial code structures, design ideas, debugging suggestions, and explanations of unfamiliar HTML and CSS concepts. 
It was particularly useful for identifying layout issues and suggesting possible solutions. 
It also helped in writing this report and the ReadME files in a much clearer and organized manner.

However, AI-generated code was not always suitable for my existing structure and sometimes introduced unnecessary changes or solutions that did not work as expected. 
It also generated code such as labels for accessibility, focus states etc., not yet covered in syllabus.
This meant I had to test the suggestions, identify errors, and adapt the code to fit my portfolio.

## Learning Outcomes

Through using AI, I gained a better understanding of HTML and CSS concepts such as sticky positioning, anchor navigation, hover, spacing, responsive layouts and CSS variables. 
I also learned to use AI more effectively as a debugging and learning tool rather than simply copying generated code. 
Comparing different suggestions and testing them in my own project helped me understand why particular solutions worked.

## Responsible Use & Modifications

I treated AI-generated content and code as suggestions rather than final solutions. 
I reviewed and tested the generated code in my portfolio, modified it to match my existing structure and design, and removed or changed parts that were unnecessary or incorrect. 
I also asked AI to explain unfamiliar code and concepts before implementing them. 
The final portfolio was adjusted based on my own design decisions, project information, and testing, ensuring that the result remained original and accurately represented my work.
